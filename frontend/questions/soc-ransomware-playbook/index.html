SOC Analyst interview question

A workstation is encrypting files and beaconing outbound. Walk me through your ransomware response.

What interviewers are really testing

  • Containment before curiosity - isolate first
  • Evidence preservation and scope assessment
  • Recovery realism: backups, verification, lessons

A strong answer framework

  1. Isolate the host from the network (keep power on to preserve memory)
  2. Confirm scope: other hosts, file shares, backup infrastructure
  3. Identify entry vector: phishing, RDP, vulnerable service
  4. Preserve evidence: memory and disk images, relevant logs
  5. Eradicate: reimage, rotate credentials, patch the entry vector
  6. Verify backups offline before recovery; involve IR, legal, comms

Follow-ups you should be ready for

  • Do you pay the ransom? Who decides?
  • How do you verify backups are clean?
  • What changes if a server is hit instead of a workstation?
Reading answers is not the same as defending them.
